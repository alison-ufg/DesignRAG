## 3. Official Artifact Submission Abstract

> **Abstract:**  
> The integration of Generative Artificial Intelligence (GenAI) into graphical user interface prototyping suffers from architectural hallucinations and compliance drift regarding proprietary Design Systems (DS). The companion paper introduces DesignRAG, a multimodal Retrieval-Augmented Generation (RAG) pipeline that enriches structured Figma API specifications with visual component thumbnails via multimodal Large Language Models (M-LLMs). This artifact package provides the complete, audited empirical infrastructure supporting the validation of DesignRAG. The package encompasses: (i) a curated dataset of 207 industrial UI components featuring raw Figma JSON hierarchies, pixel-level PNG thumbnails, and semantic contexts generated by five state-of-the-art M-LLMs (Gemini and GPT families); (ii) a stratified benchmark of 30 search intents categorized by complexity (keywords, broad intents, and specific visual intents) in English and Portuguese; (iii) raw independent multi-rater annotations from four software practitioners, evaluated via Fleiss’ Kappa (κ=0.2630) and consolidated via majority voting; (iv) complete raw inference vectors and automated Python statistical scripts for descriptive metrics (P@1, P@3, P@5, MRR) and non-parametric hypothesis testing (global Friedman test and pairwise Wilcoxon signed-rank tests with Holm-Bonferroni correction); and (v) timestamped real-time execution video demonstrations alongside a persistent Zenodo digital repository. Abiding by Open Science guidelines while honoring industrial IP constraints on backend engines, this artifact package guarantees full auditability, reproducibility, and reusability as an open benchmark for software quality assurance in AI-assisted interface engineering.

* **Keywords:** Replication Package; Design Systems; Multimodal Retrieval; Retrieval-Augmented Generation; AI-Assisted Software Engineering; Software Quality Assurance; Reproducibility.

## 5. Evaluation Criteria & Community Badges Aimed

The replication package has been curated to meet the international artifact review guidelines established by the **Brazilian Computer Society (SBC)** and the **ACM**:

### 5.1 Badge: *Artifacts Available*
* **Criterion:** Artifacts are deposited on a public, immutable digital repository with a persistent identifier (DOI) and complete metadata.
* **Compliance:** The complete replication package is permanently archived on **Zenodo** under an official DOI:
  > **Complete Repository DOI:** [https://doi.org/10.5281/zenodo.23347166](https://doi.org/10.5281/zenodo.23347166)

### 5.2 Badge: *Artifacts Evaluated – Functional*
* **Criterion:** Artifacts are thoroughly documented, self-contained, executable, and consistently replicate all scientific claims presented in the paper.
* **Compliance:**
  1. All evaluation scripts have been structured and verified to run without path or environment failures both from the repository root and from their respective subfolders;
  2. The generated script outputs faithfully recalculate the exact values reported in Table 2 and Sections 4 and 5 of the companion paper:
     - Fleiss’ Kappa = **0.2630** (Fair / Moderate Agreement);
     - Friedman Statistic = **78.344** ($p = 7.85 \times 10^{-15} < 0.0001$);
     - All 10 Wilcoxon pairwise comparisons significant at $p_{adj} < 0.05$.

### 5.3 Badge: *Artifacts Evaluated – Reusable*
* **Criterion:** Artifacts exhibit high structural quality, clear documentation, and modularity that facilitate reuse, extension, and third-party benchmarking.
* **Compliance:**
  1. The dataset of 207 Figma components (coupling JSON specifications with PNG renderings) forms a **novel empirical benchmark** for multimodal retrieval in Software Engineering and HCI;
  2. The 30 bilingual queries and consolidated ground truth provide a plug-and-play evaluation protocol for researchers benchmarking emerging M-LLMs or vector embedding strategies;
  3. The automated Python statistical framework is fully modular and directly transferable to any comparative study evaluating RAG pipelines and information retrieval systems.

## 7. Step-by-Step Reproduction Protocol for Reviewers

Reviewers can audit and reproduce all empirical results in under two minutes:

```bash
# 1. Clone or unpack the repository and enter the root directory
cd DesignRAG

# 2. Create and activate a Python virtual environment (Python >= 3.10)
python3 -m venv venv
source venv/bin/activate

# 3. Install analytical dependencies
pip install -r stats/requirements.txt

# 4. Consolidate the Ground Truth and compute expert panel agreement (Fleiss' Kappa):
python3 stats/Fleiss_Kappa/consolidated_ground_truth.py
python3 stats/Fleiss_Kappa/Fleiss_Kappa.py
# Expected Output: Fleiss' Kappa Score = 0.2630 (Moderate Agreement)

# 5. Audit descriptive retrieval metrics (P@1, P@3, P@5, and MRR):
python3 stats/Analysis_P@K_MRR/Analysis.py
# Expected Output: FTS MRR=0.36; Pure RAG MRR=0.79; Gemini 2.5 Pro MRR=1.00; Flash MRR=0.95

# 6. Audit inferential hypothesis testing (Global Friedman and pairwise Wilcoxon):
python3 stats/Friedman_Wilcoxon/Friedman_Wilcoxon.py
# Expected Output: Friedman Stat = 78.344 (p < 0.0001); Wilcoxon pairwise p_adj < 0.05
```
